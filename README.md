# osu!mania工具箱
用于改本地db文件, 方便按难度选谱
## 功能
- 自定义成绩评级
- 使用xxy算法重算SR，包括HT DT
- 谱面信息浏览器：用表达式筛选谱面，可以导出到收藏夹或CSV
